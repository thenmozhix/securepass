# SecurePass - Password Strength & Hashing Tool

## About the Project

SecurePass is a beginner-friendly Python cybersecurity project that checks password strength and generates a SHA-256 hash.

## Features

- Checks password length
- Checks uppercase letters
- Checks lowercase letters
- Checks numbers
- Checks special characters
- Classifies password as Weak, Medium, or Strong
- Generates a SHA-256 hash

## Technology Used

- Python
- hashlib

## How to Run

1. Install Python.
2. Open the project folder.
3. Run `securepass.py`.
4. Enter a test password.
5. The program displays the password strength, score, and hash.

## Project Purpose

This project was created to learn basic Python programming and understand fundamental password security concepts.
